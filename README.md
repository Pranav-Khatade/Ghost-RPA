# GhostRPA Studio

> **Autonomous, Local-First Web Automation & Vision Agent Engine**

GhostRPA Studio is a privacy-first, local-first web automation agent that uses Vision-Language Models (VLMs) to navigate and interact with web pages. By relying on visual element grounding rather than fragile DOM/HTML selectors, GhostRPA interacts with web elements visually, making it resilient to UI changes and structural updates.

---

## Key Features

* **Visual Element Grounding:** Operates based on visual layout and coordinates, bypassing traditional CSS/XPath selector breakage.
* **100% Local & Private:** Processes images and reasoning locally via Ollama. No screenshots or data are sent to third-party cloud APIs.
* **Self-Healing Loop:** Automatically verifies state changes between steps and attempts recovery actions (e.g., clearing modals via `Escape`) if no visual progress is detected.
* **Synchronous Automation Bridge:** Built-in Playwright sync engine designed for high stability across Windows and cross-platform environments.
* **Real-Time Interactive Dashboard:** Web-based control center built with FastAPI to monitor visual execution streams, agent reasoning, and live debug crosshair overlays.

---

## Architecture Overview

1. **User Request:** User provides a target URL and a natural language goal through the GhostRPA Studio Dashboard.
2. **Viewport Capture:** GhostRPA launches Chromium, loads the target page, and captures a screenshot of the viewport (`1280x720`).
3. **Visual Planning (VLM):** The local Vision-Language Model inspects the screenshot and goal, returning reasoning, action types (`click`, `type`, `scroll`, `wait`), and pixel coordinates.
4. **Action Execution:** Playwright moves the cursor, clicks, or types based on the coordinates generated by the VLM.
5. **State Verification & Self-Healing:** Captures a post-action screenshot to confirm state change before advancing or applying corrective actions.

## Prerequisites

* **Python:** Python 3.10+ (compatible up to Python 3.14).
* **Ollama:** Installed and running locally with a supported VLM (e.g., `llava`, `moondream`, or similar vision model).
* **Browsers:** Playwright Chromium binaries installed.

## Quickstart Guide

### 1. Clone the Repository
```bash
git clone https://github.com/your-username/ghost-rpa.git
cd ghost-rpa
```

### 2. Set Up Virtual Environment
```powershell
# Windows
python -m venv venv
.\venv\Scripts\activate

# Linux / macOS
python3 -m venv venv
source venv/bin/activate
```

### 3. Install Dependencies
```bash
pip install fastapi uvicorn playwright pydantic pillow
playwright install chromium
```

### 4. Ensure Ollama is Running
Ensure your local Ollama server is active and serving your chosen VLM model:
```bash
ollama run moondream # or your preferred VLM model
```

### 5. Launch GhostRPA Studio
Run the application server:
```powershell
python -m uvicorn app:app --port 8000
```

Open your browser and navigate to:
```
http://localhost:8000
```

## Usage Example

1. Open **GhostRPA Studio** at `http://localhost:8000`.
2. Enter a **Target URL** (e.g., `https://news.ycombinator.com`).
3. Enter a **Natural Language Goal** (e.g., `Click on search box and type AI Agent`).
4. Click **Launch Agent Run**.
5. Monitor the **Execution Stream** and check the **Visual Debug Frames** gallery for real-time visual coordinate overlays.
